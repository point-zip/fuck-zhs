# 智慧树刷进度

> 基于对智慧树 `ai-smart-course` 网页端播放协议的完整逆向，按**真实播放节奏**提交学习记录的油猴脚本（ScriptCat 双脚本架构）。
> 支持**整门课视频一键枚举、批量入队、后台挂机**——关掉所有课程页面也能继续刷。

---

## ✨ 功能特性

| 功能 | 说明 |
|---|---|
| 📚 整门课视频枚举 | 直接调用课程目录接口，拉取全部知识树节点 → 枚举出所有视频（名称 / fileId / 时长 / 服务端进度），一次读取约 10~40 秒 |
| ☑️ 批量勾选入队 | 清单式勾选，默认全选未完成项；同一视频被切片引用到多个节点时默认按文件合并（可关） |
| 🔄 跨页面刷进度 | 任务持久化在脚本存储里，换页面、开新标签、关掉课程页都不中断 |
| 🌙 后台挂机 | 后台引擎随浏览器常驻（`@background` + MV3 闹钟保活），**页面全关也继续刷** |
| ⏱ 真实播放节奏 | 与真实客户端逐字节同构的请求：每任务每 10 秒一个窗口（首跳 2~4 秒、后续 9.2~10 秒抖动），`study` + `report` 成对提交，`studyTime` 累计式 |
| 📊 双重进度 | 本地进度条 + 「↻ 服务端进度」按钮直接读取服务器记账（schedule 百分比、累计秒数），服务端 ≥100% 直接标记 🎉 |
| 🔀 双驱动仲裁 | 面板与后台引擎自动选主：引擎 12 秒无产出面板立即接管，面板关页引擎自动接棒，不重复提交 |
| ⚡ 并发无上限 | 并发数自由填写（默认 2），想全并行也行，风险自负 |
| 🛡 失败自愈 | 401/403 自动停任务并标注原因；网络错误自动重试 3 次；引擎 401 时自动切换显式 Cookie 重试 |

## 📦 安装

### 前置要求

- ScriptCat（脚本猫）浏览器扩展 —— [官网下载](https://scriptcat.org/)
  > ⚠️ 必须用脚本猫。后台引擎依赖脚本猫的 `@background` 能力，Tampermonkey 不支持。
- Chrome / Edge 等现代浏览器

### 安装步骤

1. 安装并启用 ScriptCat 扩展
2. 将两个脚本导入脚本猫（拖入扩展页 / 手动新建粘贴）：
   - `zhs-刷进度-任务面板.user.js` —— 面板：UI、视频枚举、任务管理、回退引擎
   - `zhs-刷进度-后台引擎.user.js` —— 后台：独立驱动刷进度，页面全关也工作
3. **两个都要启用**（只画面板也能用，但关页就停；只画引擎没有界面）
4. 脚本猫设置里允许通知/后台运行（默认即可）

## 🚀 使用指南

### 第一步：打开课程学习页

打开智慧树课程的视频学习页，地址形如：

```
https://ai-smart-course-student-pro.zhihuishu.com/learnPage/{courseId}/{节点uid}/{classId}?mapUid=xxx
                                └── 第1段=courseId    └── 第2段不用管   └── 第3段=classId
```

面板会**自动**从 URL / 页面里解析出 `courseId`、`classId`、`mapUid`，无需手填。

> 多门课：每门课一个 courseId。切到哪门课的学习页，面板自动填哪门课的参数；不同课程的任务可以共存于任务列表。

### 第二步：读取视频

点 **「📚 读取视频」**。脚本会：

1. 拉取整门课的知识树（几百个节点）
2. 逐节点查询资源列表（并发 5，约 10~40 秒）
3. 过滤出全部 mp4 视频，生成勾选清单（含时长与服务端已刷百分比）

### 第三步：批量添加

- 默认**全选**未添加的视频，可手动增减
- 「按文件合并:开」= 同一 mp4 切片引用到多个节点时只建一个任务（推荐保持开启）
- 点 **「➕ 添加选中」** 入队

### 第四步：看着它跑

- 任务添加后 ~10 秒内状态从 `…排队` 变为 `▶ 刷ing`，进度条开始走
- 每个任务按真实节奏每 10 秒提交一次（并发 N = N 个任务同时各自按 10 秒节奏跑）
- 随时点 **「↻ 服务端进度」** 查看服务器记账的真实百分比——**这个数字涨了才是真的涨了**
- 服务端显示 🎉（≥100%）即该视频完成

### 单任务操作

| 按钮 | 作用 |
|---|---|
| ⏸ / ▶ | 暂停 / 恢复该任务 |
| ↺ | 重置该任务（从任务初始位点重新刷，用于服务端没满 100% 时补刷） |
| ✕ | 删除任务 |

### 全局控制

- **⏸ 全部暂停 / ▶ 全部恢复**：跨页面生效
- **并发**：输入框直接填数字，无上限（默认 2）

## ⚙️ 工作原理（技术摘要）

脚本对智慧树协议做了完整逆向，全部请求与真实播放器**逐字节同构**：

```
密钥下发   GET  appcomm-user.../c/has?uid=RSA({module:6})
           → rt.sl = 服务端私钥加密的信封，用平台公钥 publicDecrypt 解开 → cKey

请求加密   secretStr = AES-128-CBC(载荷明文, cKey, 固定IV)
           body = {"secretStr":"...", "date":毫秒时间戳}
           头   XQJZXHIZ = AES(mapUid, cKey, IV)   ← mapUid 每门课不同，运行时自动获取

业务接口   POST kg-ai-run.../stu/studyRecord/study    {courseId,classId,knowledgeId,source,studyFileType,fileId,studyTime(累计),lastWatchTime,dateFormate}
           POST kg-ai-run.../stu/studyRecord/report   {fileId,studyTotalTime(窗口≈10s),lastWatchTime,...,dateFormate}
           POST kg-ai-run.../stu/maptree/get-tree-map-tree            ← 整门课目录树
           POST kg-ai-run.../stu/resources/list-knowledge-resource    ← 节点资源+服务端进度
```

- 所有加密用浏览器原生 WebCrypto + 自实现 RSA（无需外部库）
- **驱动仲裁**：面板与后台引擎通过共享存储的 `lastDriver/lastTickAt` 选主——谁有产出谁干活，另一方 12 秒无产出即接管，避免重复提交
- **MV3 保活**：后台引擎注册 `chrome.alarms` 30 秒闹钟，service worker 被挂起后可被唤醒补发到期的 tick
- 面板传输层优先使用页面自身 `fetch`（自动携带登录态），失败回退 `GM_xmlhttpRequest`

## ❓ 常见问题

**Q：任务一直显示"排队"？**
正常情况下添加后 ~10 秒内开始刷。若长时间排队：看面板顶部"驱动："一行——若显示"无产出"，说明引擎和面板都没跑起来，检查两个脚本是否都已启用；刷新页面让面板重新接管。

**Q：「读取视频」失败/没找到视频？**
面板会显示详细诊断（树状态码、节点数、成功/空/失败数、首个错误）。
- 401 → 登录过期，重新登录智慧树后重试
- 全部失败 → 在课程学习页上操作（面板需要页面上下文获取 mapUid）
- 空清单 → 换一门课试试；仍空请截图诊断行反馈

**Q：本地刷完了，服务端进度没到 100%？**
课程会把同一视频的**不同切片**挂到多个节点，而服务端按整个文件的时长记账。此时点该任务的 **↺ 重置**再刷一轮即可。刷新按钮可随时确认服务端真实进度。

**Q：关掉浏览器还会刷吗？**
不会。后台引擎依赖浏览器运行（浏览器开着、页面全关 = 继续刷；浏览器退出 = 停）。下次打开浏览器，引擎唤醒后会自动补上错过的 tick（不快进、只补一次）。

**Q：并发开很高会怎样？**
请求数 ≈ 并发数 × 2 次 / 10 秒。开太高请求特征明显，**账号风险自负**。建议 2~8。

**Q：支持 Tampermonkey / 油猴吗？**
面板单独可以用（Tampermonkey 装面板、不开后台），但"关页继续刷"必须 ScriptCat。

**Q：会痕量多刷或者重复扣时长吗？**
每个 tick 由存储里的时间戳占位防重；引擎与面板通过选主互斥，正常不会双发。极端切换瞬间可能有个别重复窗口，服务端自行封顶。

## 🔐 隐私说明

- 脚本**不含任何硬编码的个人数据**（无 Cookie、无账号、无课程 ID）

- 脚本内保留的 `cKey`/`IV` 为平台自身公开混淆 JS 中的全局加密常量，与用户无关
